# SRS ⇄ BDD Traceability Matrix

**Sources.** Requirements: `docs/SRS_FACIS_DCS.pdf` (text form `docs/SRS_FACIS_DCS.txt`), all 279
bracket-defined `[DCS-…]` IDs: the 249 product, interface, constraint, environment and C2PA IDs and
the 30 `[DCS-FR-UC-XX-Y]` use-case requirements. Evidence: the behave suite in `features/` and the
Playwright suite in `frontend/ClientApp/e2e` (both run on every CI push against a kind cluster,
`.github/workflows/bdd-kind.yml`), the Go and vitest unit tests (`.github/workflows/lint-and-format.yml`;
the PostgreSQL-backed Go tests run there against a Postgres service), and the chart render tests in
`deployment/helm/tests` (`deployment/helm/tests/run_all.sh`, run on every CI push by the job
`helm-chart-tests` in `.github/workflows/lint-and-format.yml`).

**Wallet scope.** The suites sign in and sign with `testWallet`, a test wallet whose keys are
files. The project claims no conformance to ARF Topic 16 (QES-scoped; the SRS descopes QES) and
no sole control or SCAL2. `testWallet` differs from the EUDI reference wallet in four verified
points, so a green CI run is not evidence of wallet interoperability.

**Method.** Every requirement gets exactly one status. Feature evidence is cited as
`features/<pack>/<file>.feature:<line>`, where the line is the `Scenario:` or
`Scenario Outline:` line; a bare `:<line>` continues the file cited before it. Go tests are
cited by name and file, Playwright specs and vitest tests by path. Most scenarios also carry the
requirement ID as a behave tag (`@DCS-…`), so `grep -r <ID> features/` finds them. A scenario
tagged `@skip` is never cited as evidence of coverage.

**Evidence scope.** The behave suite is a black-box HTTP harness against the deployed service.
Browser UI behavior is asserted by the Playwright suite and vitest; deployment properties
(TLS, probes, generated secrets, backups) by the chart render tests; process and documentation
requirements by the repository files they name. Where a row cites only configuration, design
or documentation files, no automated test asserts that part.
